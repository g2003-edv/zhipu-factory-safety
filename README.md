# 厂区智能安防监控系统
基于YOLOv8目标检测与智谱AI多模态大模型，实现厂区行人入侵实时检测，支持双摄像头自适应切换，自动留存告警截图与运行日志。

## 技术栈
Python3.11、YOLOv8、OpenCV、Pandas、智谱AI GLM-4V 多模态接口

## 核心功能
1. 双源视频输入适配：手机WiFi摄像头、本地电脑摄像头自动切换
2. YOLOv8实时画面解析，精准检测画面内行人目标
3. 智谱AI GLM-4V云端多模态模型二次校验，过滤光影、杂物、阴影带来的无效误报
4. 检测到入侵行人自动截取画面，导出告警记录CSV日志
5. 网络/云端接口异常自动降级，仅保留本地YOLO检测，监控不中断
6. 程序退出时自动输出帧率、总识别数量等运行统计指标

## 环境依赖安装
```bash
pip install opencv-python numpy pandas zhipuai ultralytics torch
```

## 运行方式
```bash
python main.py
```
按下键盘 `q` 键即可关闭监控程序

## 告警类型分类
0：环境干扰误报（光影、树枝、杂物等）
1：真实厂区行人入侵告警
2：画面模糊、遮挡，需人工复核

## 运行说明
手机WiFi摄像头需与电脑处于同一局域网；
网络波动、智谱AI接口访问失败时，程序自动切换纯本地YOLO检测模式，保障监控持续运行，不会中断画面识别。
